# Developer Portfolio - Services Page

## Overview
A modern, responsive services page cloned from [Naveen Developer's website](https://www.naveendeveloper.com/services.html) with enhanced features and premium design aesthetics.

## Features

### 🎨 Design Elements
- **Sticky Header** - Professional navigation that stays visible while scrolling
- **Profile Sidebar** - Fixed sidebar with profile card, bio, and social links
- **Hero Section** - Eye-catching introduction with availability status
- **Services Grid** - 12+ service offerings with interactive hover effects
- **FAQ Accordion** - Expandable/collapsible questions with smooth animations
- **Marquee Footer** - Continuous scrolling animation
- **Floating WhatsApp Button** - Quick contact access

### ✨ Interactive Features
- FAQ accordion with smooth expand/collapse animations
- Copy email functionality with visual feedback
- Hover effects on all interactive elements
- Scroll-triggered animations for service tags
- Parallax effect on hero section
- Ripple effect on button clicks
- Responsive mobile menu

### 📱 Responsive Design
- Fully responsive across all devices
- Mobile-first approach
- Optimized for tablets and desktops
- Smooth transitions and animations

## Usage

### Local Development
1. Clone or download the repository
2. Open `index.html` in a web browser for the main portfolio
3. Navigate to `services.html` or click "Services" in the sidebar

### XAMPP Setup
1. Place files in `C:\xampp\htdocs\Developer-Portfolio-main\`
2. Start Apache server
3. Navigate to `http://localhost/Developer-Portfolio-main/`

### Modify Services
Edit the services grid in `services.html` to add/remove services:
```html
<div class="service-tag">
  <i class="fas fa-icon-name"></i>
  <span>Service Name</span>
</div>
```

### Change Colors
Update CSS variables in `services.css`:
```css
:root {
  --primary-blue: #3B82F6;
  --cyan: #00ffcc;
  /* Add your custom colors */
}
```
